# Starbucks-Dashboard
Starbucks Customer Data Analysis Dashboard built using Power BI to analyze customer behavior, order trends, spending patterns, satisfaction levels, demographics, and order channels.

This project is an interactive Power BI dashboard developed to analyze Starbucks customer data and identify meaningful patterns in customer behavior, ordering habits, spending, and satisfactionKey Insights

 # Key Insights
- Analyzed **15K total orders** with approximately **0.2M total customer spend**.
- **Mobile App** was the most preferred order channel, followed by **Drive-Thru** and **In-Store Cashier**.
- Identified monthly fluctuations in customer order activity throughout the year.
- The **25–34 age group** represented the largest customer segment.
- Compared customer spending across different regions to identify high-spending areas.
- **Customer satisfaction rating 4** received the highest number of responses.
- Analyzed order-channel preferences across different **customer genders**.
- Compared food-item orders across different order channels.
- Used **2024 and 2025 year filters** to analyze changes in customer activity and spending.
